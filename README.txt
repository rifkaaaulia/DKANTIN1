KANTIN POLIJE - FRONT END ONLY

Cara menjalankan:
1. Ekstrak folder kantin_polije_frontend.
2. Buka folder tersebut di VS Code.
3. Jalankan index.html dengan browser (atau gunakan ekstensi Live Server).
4. Halaman login: login.html.

Daftar halaman:
- login.html       : halaman masuk
- index.html       : beranda
- menu.html        : daftar menu + filter makanan/minuman
- detail.html      : detail menu berdasarkan id
- keranjang.html   : keranjang belanja
- checkout.html    : form checkout
- pesanan.html     : pelacakan pesanan
- riwayat.html     : riwayat pesanan
- pengaturan.html  : pengaturan akun
- admin.html       : dashboard admin (contoh tampilan)

Teknologi:
- HTML untuk struktur halaman
- CSS untuk desain dan responsive layout
- JavaScript untuk interaksi sederhana
- localStorage untuk simulasi keranjang dan pesanan di browser

Catatan:
Ini murni front-end. Belum ada database, autentikasi sungguhan, API, atau proses pembayaran asli.
Gambar menu memakai URL gambar online sehingga perlu koneksi internet.
